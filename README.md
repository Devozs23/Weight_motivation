# 🏆 FitLife Pro - Plataforma Profesional de Pérdida de Peso

## 🎯 Descripción
Sistema completo multi-página para pérdida de peso con calculadoras avanzadas, análisis personalizado, seguimiento con gráficos y más de 15 recetas saludables.

## ✨ Características Principales

### 📄 Páginas Creadas:
1. **index.html** - Landing page profesional con hero section
2. **calculators.html** - Calculadoras con análisis personalizado  
3. **recipes.html** - 15+ recetas con fotos reales
4. **exercises.html** - Biblioteca de ejercicios
5. **tracker.html** - Seguimiento con Chart.js
6. **meal-planner.html** - Planificador semanal

### 🧮 Calculadoras Avanzadas con Análisis:
- **IMC** con mensajes personalizados ("Te faltan X kg para peso normal")
- **Calorías** con recomendaciones específicas
- **Macros** optimizados según objetivo
- **Agua** basada en peso y actividad
- **Peso Ideal** con rangos saludables  
- **Grasa Corporal** con categorías detalladas

### 🎨 Diseño Profesional:
- ✅ Navegación sticky multi-página
- ✅ Hero section con animaciones
- ✅ Gradientes modernos
- ✅ Responsive design completo
- ✅ Font Awesome icons

### 📊 Funcionalidades Avanzadas:

## 🚀 Cómo Usar

1. Abre `index.html` en tu navegador
2. Navega por las diferentes páginas
3. Usa las calculadoras para análisis personalizado
4. Explora recetas y ejercicios
5. Rastrea tu progreso en la página de tracker
